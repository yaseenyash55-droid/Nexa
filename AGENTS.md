# AGENTS.md — Nexa Oracle Social Application Guidance

## Architecture & Code Boundaries
- **Monorepo Structure**: Root npm workspace with `client/` (React + Vite + TypeScript + Tailwind) and `server/` (Node.js + Express + TypeScript + `oracledb`).
- **Layered Architecture**: Route -> Validation Middleware -> Controller -> Service -> Repository -> Oracle Database.
- **Oracle-Only Operation**: All runtime data access uses Oracle Database repositories.
- **No Silent Fallbacks**: Database errors MUST return sanitized 500 responses and degraded health status.

## Oracle Database Conventions & Rules
- **Identifiers**: Unquoted uppercase (`USERS`, `POSTS`, `COMMENTS`, `LIKES`, `FOLLOWERS`, `REFRESH_TOKENS`, `BOOKMARKS`, `NOTIFICATIONS`).
- **Primary Keys**: `NUMBER GENERATED BY DEFAULT ON NULL AS IDENTITY`.
- **Timestamps**: `TIMESTAMP WITH TIME ZONE DEFAULT SYSTIMESTAMP`.
- **Booleans**: Oracle 19c/21c does not support native SQL BOOLEAN in table columns; use `NUMBER(1)` with `CHECK (col IN (0, 1))`.
- **Bind Variables**: Always use bind variables (`:1`, `:2` or named `:param`) for all dynamic inputs.
- **Transactions**: Explicit `commit()` and `rollback()` handling using `finally` blocks for connection release.

## UI/UX & Design System
- **Theme**: Premium dark mode with deep navy/graphite backgrounds (`#0b0f19`, `#151e2e`), indigo-violet primary accents (`#6366f1`), and cyan secondary accents.
- **Responsiveness**: Responsive container across mobile (360px), tablet (768px), and desktop (1024px+).
- **Accessibility**: High-contrast text, clear focus rings, semantic landmark tags, and keyboard navigable controls.

## Development & Verification Commands
- `npm run dev`: Starts server (4000) and client (5173) concurrently.
- `npm run typecheck`: Runs strict TypeScript check on server and client.
- `npm run test`: Executes Vitest test suite for backend and frontend.
- `npm run build`: Compiles production assets.
