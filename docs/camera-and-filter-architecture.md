# Nexa Real-Time Camera & Filter Architecture

## 1. Web Camera Pipeline
- Built using HTML5 `navigator.mediaDevices.getUserMedia()` and Canvas 2D / WebGL rendering.
- Real-Time Presets: `Vintage Warmth`, `Cyberpunk Neon`, `Dramatic B&W`, `Retro VHS`.

## 2. Beauty Standard & Body Reshaping Guard
- Prohibits facial slimming, lip enlargement, body warping, or skin bleaching.
- Enforces non-destructive aesthetic filters only.
